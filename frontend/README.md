# Waypoint AI Frontend

The frontend uses React, TypeScript, and Vite, with Leaflet isolated behind `src/widgets/map/`. The browser communicates with the backend over HTTP and WebSocket and never connects directly to PostgreSQL or Ollama.

See the [frontend guide](../docs/frontend.md), [system workflow](../docs/system-workflow.md), and [stack decision](../docs/stack-decision.md).
